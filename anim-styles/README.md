# ستايلات الأنيميشن بأمر واحد 🎬 — من @tazmkw

6 أوامر (Skills) لـ **Claude Code**: تكتب اسم الستايل وموضوعك بكلمتين، وClaude يبني لك فيديو أنيميشن عمودي بالكود (Remotion) ويعطيك رابط المعاينة.

| الأمر | الستايل | مثال |
|---|---|---|
| `/ink-doodle` | رسم بالقلم (ستيك مان) | `/ink-doodle قبل الجوالات` |
| `/neon-silhouette` | ظل بالغروب | `/neon-silhouette التسليم الساعة 10` |
| `/blue-grid` | شرح ثلاثي الأبعاد | `/blue-grid شلون يشتغل المكيف` |
| `/pov-doodle` | دودل يومياتك | `/pov-doodle حياتك كموظف` |
| `/red-relief` | خريطة تاريخية | `/red-relief طريق الحرير` |
| `/glow-world` | عالم مضيء | `/glow-world داخل عقل الذكاء الاصطناعي` |

## التركيب (أسهل طريقة)
افتح Claude Code والصق هالسطر:

```
ثبّت لي سكيلات الأنيميشن من https://github.com/sli101/tazm-skills/tree/main/anim-styles — انسخ المجلدات الست (ink-doodle, neon-silhouette, blue-grid, pov-doodle, red-relief, glow-world) إلى ~/.claude/skills/
```

بعدها افتح مجلد فاضي واكتب مثلاً: `/ink-doodle قبل الجوالات`

## وش تحتاج؟
1. **Claude Code** (يجي مع اشتراك Claude).
2. **Node.js** على جهازك.
3. **Remotion** (المكتبة اللي تبني الفيديو) تنزل بروحها — مجانية للأفراد والشركات لين 3 أشخاص.

## نصايح
- الموضوع بكلمتين أحسن من جملة طويلة: «زحمة الدائري» أحسن من «أبي فيديو عن الزحمة اللي…».
- ما عجبك؟ قل له «أسرع» أو «لون ثاني» أو «خله 10 ثواني» ويعدّل.
- تقدر تخلط: «/blue-grid شلون يشتغل الجوال، بس بألوان glow-world».
