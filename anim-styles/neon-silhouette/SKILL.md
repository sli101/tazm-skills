# /neon-silhouette — ظل بالغروب (من @tazmkw)

## الطريقة (نفسها لكل ستايلات @tazmkw)

المستخدم يكتب: `/neon-silhouette <موضوعه بكلمتين>` — مثلاً `/neon-silhouette التسليم الساعة 10`.
لو ما كتب موضوع، اسأله سؤال واحد: «وش الموضوع؟» وبس.

1. **المشروع:** لو المجلد الحالي فاضي، سوّ مشروع Remotion جديد:
   `npx create-video@latest . --template blank` (لو سأل، اختار الإعدادات الافتراضية)، وبعدها `npm i`.
   لو فيه مشروع Remotion أصلاً، أضف تركيبة جديدة بداله.
2. **التركيبة:** `NeonSilhouette` — 1080×1920 (عمودي)، 30 فريم/ث، **6 ثواني**.
   كل الرسم بالكود: SVG وdiv وCSS (و`@remotion/three` للستايلات الثلاثية الأبعاد). **لا صور من النت ولا مولّد صور** — كل شي يترسم.
3. **العنوان فوق:** الموضوع نفسه كسؤال أو جملة قصيرة (≤6 كلمات) بنفس لغة المستخدم، بأعلى الشاشة (y≈250–420)، يبين من أول فريم.
   الخط العربي: حمّل `Noto Kufi Arabic` أو `Cairo` من `@remotion/google-fonts`. كل كلمة عربية كاملة بعنصر واحد (لا تقطّع الكلمة ولا `letter-spacing`)، واتجاه `rtl`.
4. **الحركة:** أول فريم فيه شي يتحرك (مو شاشة فاضية). حدث جديد كل ~1 ثانية (شي يدخل، رقم يتقلب، الكاميرا تقرب). استخدم `spring()` و`interpolate()` بس، بدون CSS animations.
5. **القصة بثلاث ضربات:** بداية (المشهد) ← تصعيد (المشكلة/الحركة الكبيرة) ← نهاية لها ضربة (نكتة صغيرة، كشف، أو رقم).
6. **المعاينة:** شغّل `npx remotion studio` وعطه الرابط. ولو طلب فيديو: `npx remotion render NeonSilhouette out/neon-silhouette.mp4`.
7. **بعدها** اسأله سطر واحد: «تبي أغيّر شي؟ (أطول، أسرع، لون ثاني، موضوع ثاني)».

## الستايل: ظل بالغروب
- **الشكل:** غرفة مظلمة، شخص ظل (لون واحد #191430 تقريباً) قاعد قدام شباك كبير.
- **ورا الشباك:** غروب بتدرج بنفسجي ← وردي ← برتقالي، وعماير ظل فيها شبابيك صفرا تولع وتطفي عشوائياً.
- **الإضاءة:** لمبة مكتب تعطي مثلث نور أصفر شفاف. كل شي ثاني ظل.
- **الضربة:** ساعة رقمية بخط mono كبير (مثل 21:59) الأرقام تتقلب، ومع آخر رقم: هزة خفيفة للكاميرا والنور يرجف.
- **الحركة:** الكاميرا تقرب ببطء شديد (scale 1 ← 1.08) طول الفيديو، والشبابيك تولع وحدة وحدة.
- **الجو:** هادي وثقيل. العنوان أبيض على شريط أسود فوق الشباك.
