# tazm-skills — سكيلز Claude بالخليجي من @tazmkw

كل مجلد هنا = **Skill** جاهز لـ Claude. تنزّله، ترفعه، وClaude يصير يعرف يسوي الشغلة كل مرة بنفس الطريقة.
كل سكيل له ريل على إنستغرام يوريك Claude وهو يسويه فعلاً: [@tazmkw](https://www.instagram.com/tazmkw/)

## شلون تركّبه (claude.ai — دقيقة وحدة)
1. نزّل مجلد السكيل كملف zip (أو نزّل الريبو كامل: **Code ← Download ZIP** وخذ المجلد اللي تبيه واضغطه zip).
2. افتح claude.ai ← من القائمة الجانبية **Customize ← Skills ← Add** وارفع الـ zip.
3. لو طلب منك، شغّل **Code execution** من **Settings ← Capabilities** (السكيلز متاحة حتى بالخطة المجانية).
4. خلاص — اطلب الشغلة عادي بالمحادثة («لخّص القروب») وClaude يستخدم السكيل بروحه.

> Claude Code: انسخ المجلد إلى `~/.claude/skills/` (أو `.claude/skills/` داخل مشروعك).

## السكيلز
| السكيل | وش يسوي | الريل |
|---|---|---|
| [`claude-reel-maker`](claude-reel-maker/) | Claude Code يسوي ريل إنستغرام كامل من سطر واحد: سكربت خليجي، صوت، مونتاج بالكود، غلاف، كابشن، ونشر | «أنا Claude… وسويت هالريل» |
| [`whatsapp-group-summary`](whatsapp-group-summary/) | يلخص قروب الواتساب: المواعيد، اللي طلبوه منك، الفلوس، ومسودات ردود | قريباً |

## خصوصية
السكيلز ما ترسل بياناتك لأي مكان — كل شي يصير داخل محادثتك مع Claude. بس لا ترفع ملفات سرية (قروبات الشغل، أرقام، عقود فيها بيانات حساسة).
